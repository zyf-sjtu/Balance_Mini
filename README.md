# 轮腿教具小车

## 任务目标

> 在这个任务里，你需要在一些辅助下完成一个轮腿小车的控制程序并对参数进行调试。
>
> 先进行目标性能的设定，完成demo版本代码，自主评估调试效果，对目标性能进行修订，最后完善你的demo成为一个相对安全稳定可用的轮腿机器人控制代码。

## 目标性能

| 优先级 |    功能    | 性能标准 |
|-----|:--------:|:-----|
| P0  |   正常平衡   |      |
| P0  | 跟随指令正常平移 |      |

**↑** 需要你去思考补充
